# 联网问答、地图与语音

校园问答和内容生成会自动搜索公开网页；普通聊天在请求查询、最新信息或事实说明时启动检索。后端使用 DDGS，优先排列教育机构和政府来源，最多读取三页正文。只把当前主题提交给搜索服务，不附带完整会话或设备坐标。搜索服务限时12秒、缓存10分钟，失败时继续由原 GLM 提供基本解释或创作草稿，明确尚未核实的信息。

引用格式问题不再导致整段答案失败。不存在于本次资料中的来源ID替换为“来源待核验”，缺失引用或无法对应的网址附资料提示；参考资料不代表逐句核验通过。模型认证失败、网络超时、空正文和截断依然显示真实错误。

`CAMPUS_WEB_SEARCH_ENABLED=false` 可停用搜索。搜索采用公开搜索引擎，可能受网络、限流或站点访问限制；这不等于拥有完整馆藏数据库。藏品目录仍应由真实馆方资料维护。

高德 Web 端（JS API）的 Key 写入根 `.env` 的 `CAMPUS_AMAP_JS_KEY`，配套安全密钥写入 `CAMPUS_AMAP_SECURITY_KEY`。安全密钥只在后端代理转发时加入。JS 请求保留 `s=rsv3`、`platform=JS`，不能把 JS Key 当作独立 Web 服务 Key 使用。

有配置时默认载入在线地图。定位须点击开始，提供一次定位、每30秒持续更新、IP城市定位和持续IP城市定位；停止、切校区或离开页面会取消本地等待和后续更新，后台页面暂停轮询。IP位置仅表示出口IP所属城市或粗略区域，VPN/代理可能改变结果；不作为精确步行导航起点。地图坐标不进入模型、日志或Git。

地图使用按日期保存的应用发起次数上限：加载100、定位3000、POI搜索100、路线200；仍有限频且不自动规划路线。这是应用计数，不等于高德控制台实际额度。原隔离测试保留低额度fixture。

语音菜单只保留现有 Xiaoxiao 女声、Yunxi 普通话男声、HiuGaai 粤语和 Jenny 英语。继续使用现有 Edge TTS，不是角色克隆音色。浏览器操作系统音色不再混入菜单。

启动：`scripts/start-app.ps1 -Build`，打开 http://127.0.0.1:8000 。修改 `.env` 后需重启本项目服务。统一离线回归：`scripts/check-r2.ps1`；真实服务验收与离线fixture分开记录。
